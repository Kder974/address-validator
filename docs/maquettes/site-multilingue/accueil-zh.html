工作原理

一次请求，三个步骤。

无需维护地址库，也无需自写规则。客户输入地址时，调用 API 即可。

  1. 01

    发送

    您的商店、脚本或智能体将街道、城市、州、邮编和国家，按客户输入的原样发送。

    "street": "100 stewart st"
  2. 02

    接收

    API 返回标准化地址、GPS 坐标、可送达性，以及 0 到 1 的置信度。

    "line1": "100 Stewart Street"
  3. 03

    发货

    地址确认无误，包裹即可发出。否则，发货前先与客户核实。已验证过的地址直接读取缓存，不会重复计费。

    "deliverability": "residential"

从备货到送达，地址始终准确。
