Bien utiliser le service

Six habitudes qui évitent les colis perdus et font durer votre quota.

  1. Vérifiez au moment de la commande

    Pas au moment d'imprimer l'étiquette : si l'adresse est fausse, le client est encore là pour la corriger.

  2. Une adresse, une seule validation

    Chaque appel compte dans votre quota, même pour une adresse déjà vérifiée. Gardez le résultat avec la commande.

  3. Adresse invalide ? Demandez au client

    Un message simple, « votre adresse semble incomplète, pouvez-vous la vérifier ? », règle la plupart des cas avant l'envoi.

  4. Envoyez seulement l'adresse

    Rue, ville, code postal, région et pays en deux lettres (FR, RE, US). Jamais le nom ni l'email du client : l'API n'en a pas besoin.

  5. Gardez votre clé côté serveur

    Jamais dans le code visible de votre boutique. Si elle a circulé, régénérez-la ici : l'ancienne s'arrête aussitôt.

  6. Sachez où le service est le plus précis

    La vérification est optimisée pour les États-Unis. Ailleurs, La Réunion et la France comprises, elle est partielle : gardez un œil sur les cas douteux.
