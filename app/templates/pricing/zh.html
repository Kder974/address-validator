工作原理

一次请求，三个步骤。

API 会标准化街道、城市和邮政编码，定位地址，并判断是否可送达。存疑的地址会在寄出前先行处理。

  1. 01

    发送地址

    从您的后台、订单 webhook 或电子表格发起一次 POST /validate 调用，传入街道、城市、州、邮政编码和国家。

    "street": "100 stewart st"
  2. 02

    接收验证结果

    标准化地址、GPS 坐标、可送达性，以及 0 到 1 的置信度。

    "deliverability": "residential"
  3. 03

    寄出更正后的地址

    存疑的地址会在交给承运商之前被更正，或先搁置。避免退货，就发生在这一步。

    "line1": "100 Stewart Street"

应用场景

核验可以接入的地方。

电商

在下单时核验地址。地址存疑的话，发货前先联系客户。

物流

把发货文件交给承运商之前先核验。指南提供了可按需修改的 CSV 导入脚本。

电商平台

让卖家在注册时就提供经过核实的地址，而不是事后再去处理退货。

免费试用需要信用卡吗？

不需要。试用期 {{jours_essai}} 天，含 {{validations_essai}} 次验证，无需信用卡，无合约期限。结束后，您可以选择一个套餐；不选的话，什么都不会发生。

超出额度会怎样？

额度按月计算，每月 1 日（UTC）重置。用完后，API 会返回 402 和 quota_atteint：不会额外收费，也不会自动扣款。您可以在客户中心查看用量。如需升级到更高的套餐，请写信联系我们。

我发送的地址会怎样处理？

地址仅用于验证。缓存以 SHA-256 指纹为索引，保存标准化后的地址 {{jours_cache}} 天，之后删除。不会转售，也不会用于广告。

是否覆盖留尼汪和其他国际地址？

美国地址已优化（USPS DPV）；法国及海外省由国家地址库（BAN）核验；其他国家地址可以提交，但仍为部分验证：返回结果不代表已完整确认。已知限制已在 API 清单文件中公布。

集成需要多长时间？

第一次调用几分钟即可完成：发起 POST /validate，并把密钥放在请求头 X-API-Key 中。接入订单时，指南涵盖直接调用、CSV 导入、Shopify 和 WooCommerce，并附代码示例。无需安装 Shopify 应用：调用从您自己的服务发出。
